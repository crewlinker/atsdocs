Sterndesk Recruit supports the Model Context Protocol (MCP), allowing AI assistants to connect directly to your Sterndesk Recruit data and tools.

With MCP, you can use supported AI assistants such as [Claude](/connect-to-claude) and [ChatGPT](/connect-to-chat-gpt) to find and retrieve recruitment information without manually switching between Sterndesk and your AI assistant.

For example, you can ask:

- “Find Chief Engineers with PSV experience.”
- “Find candidates with experience as a Second Officer.”
- “Show me the profile information for this candidate.”

The AI assistant can use the available Sterndesk Recruit tools to retrieve relevant information from your organization.

## How it works

Your AI assistant connects to the Sterndesk Recruit MCP server.

When you make a request that requires information from Sterndesk, the assistant can use the available Sterndesk Recruit tools to retrieve that information.

The production MCP server is available at:

[**https://edge.sterndesk.com/mcp**](https://edge.sterndesk.com/mcp)

## What you can access

The current MCP integration provides access to Sterndesk Recruit methods available for reading data.

This includes functionality for finding crew and retrieving candidate information.

The currently documented MCP integration is intended for retrieving data. Actions that modify Sterndesk data are not currently supported for general use.

## Authentication

Sterndesk Recruit MCP supports OAuth authentication for connecting supported AI assistants, including [Claude Desktop](/connect-to-claude) and [ChatGPT](/connect-to-chat-gpt).

When configuring the connector, select OAuth authentication and follow the connection process provided by your AI assistant.

You do not need to create a personal API key or manually configure an Authorization header when connecting through OAuth.

Personal API keys remain available for accessing the Sterndesk REST API. See the [Authentication](/authentication) guide for details.

## Connect an AI assistant

You can add Sterndesk Recruit as a custom connector in supported AI assistants.

Follow the setup guide for your preferred assistant:

- [Connect to Claude](/connect-to-claude)
- [Connect to ChatGPT](/connect-to-chat-gpt)

For more information about the Sterndesk API, see the [API overview](/api-reference/overview).
